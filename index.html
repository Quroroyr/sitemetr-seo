Не список из трёхсот ошибок, а очередь работ

Каждая находка — с баллами: насколько вырастет оценка, если её исправить. Сверху то, что даст больше всего.

  • Технический аудитМета-теги, canonical, robots.txt, sitemap, редиректы, коды ответа, дубли, битые ссылки.
  • Скорость и Core Web VitalsLCP, CLS, TTFB с отрисовкой в браузере, вес страниц, блокирующие ресурсы, картинки.
  • Безопасность и доступностьHTTPS, HSTS, заголовки безопасности, смешанный контент, проверки доступности axe.
  • Микроразметка, соцсети, AI-поискJSON-LD, Open Graph, готовность к нейросетевому поиску.

То, чего нет в западных аудиторах

Два отдельных раздела с правилами под рунет: «Яндекс» для любого сайта и «1С-Битрикс», который появляется, только если сайт на Битриксе. На остальных сайтах он не влияет на оценку.

На какие запросы ответить на сайте

Перетащите выгрузку запросов из Search Console или Яндекс.Вебмастера во вкладку «Запросы» — CSV, ZIP или Excel, распаковывать ничего не нужно. Файл никуда не отправляется.

  • 12 групп запросовВопросы, инструкции, «что это такое», проблемы, сравнения, «купить и цены», город, запросы в стиле нейросети, длинный хвост, «почти в топе», «много показов — мало кликов».
  • Упущенные кликиСколько кликов обычно даёт такая позиция сверх полученных. Сверху — с чего начинать.
  • Фильтр для Search ConsoleГотовое регулярное выражение в одну кнопку. Работает с кириллицей — в отличие от популярных английских, где \b не видит русских слов.

Отчёт, который не стыдно отправить клиенту

«Экспорт → Отчёт для клиента» сохраняет PDF: оценка, пять главных исправлений с баллами, оценка по разделам и вся очередь работ с подсказками «как исправить». Есть экспорт в HTML, Markdown и JSON.

Установка за минуту

Установщик не подписан платным сертификатом, поэтому Windows при первом запуске предупредит. Это нормально для бесплатных программ.

  1. Скачайте установщикФайл Sitemetr-8.1.2-win-x64.exe, около 100 МБ.
  2. Разрешите запускВ окне «Система Windows защитила ваш компьютер» нажмите «Подробнее», затем «Выполнить в любом случае».
  3. Проверьте сайт«Новая проверка» → адрес сайта → «Проверить». Для замеров скорости включите Core Web Vitals.

Есть и консольная версия

Для автоматизации и CI: тот же движок, вывод в JSON, HTML, Markdown или PDF, коды выхода для проверок качества. Нужен Node.js 20+.

# из исходников
git clone https://github.com/Quroroyr/sitemetr-seo.git
cd sitemetr-seo
npm ci && npm run build

# проверка с обходом сайта и PDF-отчётом
node dist/cli.js audit https://example.ru \
  --crawl --max-pages 20 --format pdf -o report.pdf

Вопросы

Это бесплатно?

Да. Код открыт под лицензией MIT: можно пользоваться, менять и распространять, в том числе в коммерческой работе.

Куда уходят данные о сайтах?

Никуда. Проверки выполняются на вашем компьютере, история хранится в локальной базе. Сайтметр обращается только к проверяемому сайту и к ссылкам с него, когда проверяет, не битые ли они.

Есть версия для macOS или Linux?

Готовый установщик пока только для Windows. Консольная версия и веб-панель (sitemetr serve) из исходников работают везде, где есть Node.js.

Сайт открывается только через VPN — проверка не идёт

Пока движок не использует системный прокси, поэтому сайты, доступные только через VPN, проверить не получится. Включите VPN в режиме всей системы (TUN) или проверяйте сайт, доступный напрямую.
